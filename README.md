# config-i3
Minha configuração do i3

## Programas
* Rofi
* Kitty

## W A S D
Para um sistema de direção mais "padrão", preferi usar as teclas w a s d ou as setas + o mod4 ou (Windows). <br>
Para direção entre workspace use o shift + left / right ou o numero do workspace (1..0)

## Atalhos de programas
* $mod + Space - rofi
* $mod + t - Kitty
* $mod + q - Kill
* $mod + c - Recarrega a configuração
* $mod + s - Screenshot (ainda não testado)

## Layout
* $mod + Shift + Scape - Scratchpad move
* $mod + Scape - Scratchpad show
* $mod + Shift + Space - Stacking
* $mod + f - Fullscreen toggle
* $mod + h - Toggle split
* $mod + v - Toggle split

## Modos
* $mod + m - move: permite mover o container
* $mod + r - resize: permite redimensionar o container

##
### Observações
* Os atalhos de áudios permaneceram os mesmos
* Para sair de um container use o mesmo atalho, esc ou enter
